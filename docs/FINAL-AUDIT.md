# Финальная проверка GD Store

Дата: 22 сентября 2026. Основа: интегрированная версия после пяти патчей, коммит `548e3e8`.

## Результат

Все основные разделы остаются подключены к Django: аккаунты, магазин, заказы, библиотека, друзья и чаты, сообщество, мастерская, поддержка, события, команды, коллекции и демокошелёк. Изменены данные и поведение, существующий CSS, расположение блоков и навигация сохранены.

### Новый каталог

| Игра | Представленная версия / платформы | Оформление |
| --- | --- | --- |
| Grand Theft Auto V | Enhanced, ПК Windows | Учебная цена 599 ₴ |
| Grand Theft Auto VI | PlayStation 5, Xbox Series X\|S | Учебный предзаказ, 2999 ₴ |
| Counter-Strike 2 | ПК Windows / Linux | Бесплатная базовая игра, без Prime Status |
| Dota 2 | ПК Windows / Linux / macOS | Бесплатно |

Цены GTA здесь заданы для проверки учебного магазина. Настоящие деньги не списываются, лицензии и игровые ключи не выдаются. GTA VI не обозначается как версия для ПК. Объявленная дата её релиза — 19 ноября 2026; администратор может обновить сведения при изменении официального анонса.

С витрины сняты ORBITAL, ASHEN CROWN, VELOCITY/2099, ECHOES OF ELION, HOLLOW KINGDOM и NIGHTSHIFT. Физическое удаление не применяется: ранее купленная игра остаётся доступной владельцу как запись библиотеки, а заказ и подарок не теряют ссылку на неё. Повторный `seed_catalog` не затирает цену, текст или обложку, изменённые администратором.

## Что найдено и исправлено

1. **Каталог зависел от старых игровых идентификаторов.** Убраны обязательные значения `orbital` из форм профиля, мастерской и событий. Жанры берутся из опубликованного каталога. Уведомление «в игре» больше не приписывает пользователю ORBITAL. Баннеры магазина баллов связаны с новыми играми.
2. **Предзаказ был бы обычной покупкой.** Добавлены поля игры `is_preorder`, `platforms`, `official_url` и снимок `OrderItem.is_preorder`. Корзина, подтверждение, чек, библиотека и история различают предзаказ. Запись библиотеки означает учебное резервирование, не готовый игровой клиент. Снятие флажка администратором после релиза открывает обычное состояние игры.
3. **Старое подтверждение не учитывало изменение условий релиза.** Оба API покупки привязывают подтверждение к флажку предзаказа, дате и платформе. Изменение любого значения требует нового расчёта. Цена, получатель, права и промокод по-прежнему перепроверяются внутри транзакции.
4. **Предзаказ позволял бы оставить отзыв до выхода игры.** Запрет добавлен на сервере в оба API отзывов и отражён в форме. После возврата покупатель также не может изменять отзыв через старый REST API без игры в библиотеке.
5. **Рейтинг был выдуманным.** Теперь процент положительных отзывов и их количество считаются по таблице отзывов GD Store. Пустой каталог отзывов показывает «Нет отзывов». Выдуманная коллекция достижений заменена честным состоянием отсутствия интеграции.
6. **Отрицательная цена могла попасть в данные товара.** Добавлены валидация цены и ограничения БД: цена неотрицательна, скидка не больше 100%. Поля доступны в админке и API управления каталогом.
7. **Нулевые заказы создавали бесполезные записи баланса.** CS2 и Dota 2 можно получить при нулевом балансе. Нулевые списания и начисления баллов не записываются; повтор одного запроса не создаёт вторую покупку.
8. **Возвращённый подарок выглядел полученным.** Убрано повторное всплытие возвращённых подарков, исправлен их статус и ожидание ответа сервера при открытии. Карточка игры сохраняется для истории получателя даже после возврата и снятия с продажи.
9. **Некорректное тело запроса расчёта давало ошибку сервера.** Вместо этого сервер возвращает ошибку валидации 400.
10. **CI запускался только для pull request.** Проверки также включены для прямого push в main. Это не означает, что удалённый CI уже завершился; ниже перечислены локально выполненные проверки.

## Границы готовности

Проект пригоден для учебной демонстрации. Настоящие платежи, доставка лицензий, запуск игры, синхронизация игрового прогресса и отправка почты не реализуются. Служба поддержки работает внутри сайта; мастерская хранит ZIP-файлы и выдаёт их после проверки доступа. Чаты обновляются опросом примерно каждые 5 секунд.

SQL Server и Docker в этой проверке не запускались. Для массового публичного магазина нужны отдельные проверки нагрузки, настройка production-сервера, HTTPS, резервного копирования и реального платёжного провайдера. Тестовые настройки с быстрым хешером нельзя использовать при обычном запуске.

## Управление играми

Откройте `http://127.0.0.1:8000/admin/` → Catalog → Games. Редактируйте цену, скидку, текст, изображение, платформы, дату и флажки публикации/предзаказа. Снятие публикации убирает игру из продажи; записи истории остаются. После выхода GTA VI вручную снимите флажок «Предзаказ». Обычный запуск использует `.env`, где для учебной оплаты требуется `PAYMENT_TEST_MODE=1`.

Обновление существующей установки: резервная копия базы и пользовательских файлов → `manage.py migrate` → `manage.py seed_catalog` → перезапуск Django/Vite. Подробнее — в README.
